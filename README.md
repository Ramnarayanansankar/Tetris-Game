# Infinite Quiz Pro (v2.0 - Dynamic)
### The Personalized Knowledge Challenge

This advanced version of **Infinite Quiz Pro** puts the power in the player's hands. By integrating dynamic category fetching, players can specialize in their favorite subjects or challenge themselves with a random mix of global knowledge.

## ✨ Key Enhancements
- **Dynamic Topic Selection:** On startup, the game fetches 20+ real-time categories (Science, History, Film, Sports, etc.) directly from the global database.
- **"Mix of All" Mode:** For the ultimate general knowledge test, choose the "Mix" option to pull questions from any category.
- **Enhanced Logic:** Improved API error handling to ensure a smooth transition between difficulty levels and specific subject requests.
- **Responsive Top-Bar:** Real-time tracking of current category, score, and difficulty setting.

## 🎮 How to Play
1. **Choose Your Topic:** Use the dropdown menu to pick a specific interest or keep it on "Mix."
2. **Select Difficulty:** Click one of the three levels to launch the session.
3. **Use Hints Wisely:** You get one hint per question—use it when you're truly stumped!
4. **Quit Safely:** The "Quit" button allows you to return to the main menu and reset your stats.

## ⚙️ Installation & Customization
No installation or dependencies required. This is a "Portable Web App"—just one file.
- **Customization:** To change the theme, edit the `background` CSS property inside the `<style>` tag.
- **Requirements:** Requires a stable internet connection for real-time question fetching.
